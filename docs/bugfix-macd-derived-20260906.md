# B06：MACD 接入收尾

状态：本地代码与真实端到端通过，未发布。公网仍为011。

## 原因

`mx_indicator_contract.py` 的 MACD 未支持原因是预配置文案“真实列和默认周期已找到，但后复权参数尚未通过验证”。MACD 未进入供应商字段白名单，执行前即拒绝。这不是本次请求返回了错误 MACD 字段，也没有本次证据证明供应商数值错误。

必要的边界是指标必须与回测使用同一价格口径和参数；不应把“尚未验证成品指标”误写成供应商当前故障，或因此永久禁用已有本地公式的指标。

## 最小修复

- 在既有 Skill 日线派生白名单中显式接入 `technical.macd`，复用 `SignalRuntime`，没有重写引擎。
- 使用东方财富后复权收盘价计算 DIF=EMA(fast)−EMA(slow)、DEA=EMA(DIF,signal)、柱值=2×(DIF−DEA)。本例默认12／26／9，比较相邻有效日 DIF／DEA 的金叉与死叉。
- 保留行情完整性、交易状态、复权字段及交易时点检查；不修改供应商 MACD 字段为 verified，不放开其他未支持指标。
- 默认向前取180自然日预热；零成交日不推进EMA。首个有效值初始化，slow+signal−1个有效日后输出数值，再多一个有效日判断交叉。递推初值可能影响早期数值，不承诺与其他终端逐点相同。
- 报告明确来源为 `local_formula_on_eastmoney_skill_ohlcv`，不是供应商成品MACD；信号收盘确认，下一可交易日开盘尝试成交。
