# 单只 A 股策略组合开发

目标：自然语言规则生成、审阅编辑、共享账户执行、报告恢复贯通；本地真实验收后再公开发布。不包含多股票组合回测。

## 本轮已核实

- 后端公共 StrategySpec 已有 independent_plans，保存买入与卖出两个独立计划；已有共享账户执行适配及 API 契约测试。早期文档中“只有内部合同”的描述不能代表当前代码。
- 前端 StrategySpec 尚未声明 independent_plans；模型语言适配目录中也尚未发现该字段。仍需核对编译入口、候选结构、编辑保存及报告恢复，不能宣布双计划端到端可用。
- 网格审阅卡此前会在任一网格侧存在时隐藏全部买卖行。现已在同一流程卡按买入、卖出、区间顺序保留网格侧和独立条件侧，并恢复独立条件编辑及区间编辑入口。具体网格参数仍放高级设置。
- 原组合 API 矩阵中两个失败断言把买卖成交误等同于完成清仓。改为从实际成交重算持仓、现金、费用、期末权益与清仓次数，不要求合法组合必须清仓。
