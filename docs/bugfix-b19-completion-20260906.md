## 用户确认的执行含义

“持有满10天 且 RSI高于55”：满10个后续交易日后，持有期条件持续成立；继续等同一天收盘RSI也高于55，再于下一可交易日尝试卖出。不在第10天单独卖出，也不把更早某天的RSI满足状态沿用到后来。停牌等成交约束继续生效。

## 本地改动

- 退出顶层 DSL 支持 `all`，主 Skill 日线执行引擎同时判断市场条件与持仓条件；止损、回撤、持有期均参与判断。原 `first_of` 保持先触发退出。
- 市场条件取数聚合跟随 ALL／ANY，不把 ALL 取数误合并为 OR。旧 daily 引擎尚未实现该语义，明确拒绝 ALL，不能静默跑错。
- 卖出关系切换保存真实操作符；修复单个嵌套 ALL 仍显示“任一触发”的问题；单个条件不显示有意义的关系切换（控件禁用）。
- 已有财务条件支持比较符／数值，事件支持已有属性及已有文本匹配参数；保留原指标、事件代码及数据口径。此范围不等于新增任意财务指标或事件目录。
- 原分组虚线、编号、二级编辑、无框日期入口、简洁标题保留。
