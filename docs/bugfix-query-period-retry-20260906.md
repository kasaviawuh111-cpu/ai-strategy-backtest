## 本轮结论

“最近一个交易日成交额最高的 3 只 A 股”已在真实页面返回单日日期、股票名称及成交额；已知股票的单日收盘价查询也通过。B06、B12、B13 均保持**局部已修待用户验收**，不代表全部查询、复合条件或回测已修复。

普通筛选由同一次模型调用核对返回口径并组织完整回答，核对通过后直接显示它的 `review.message`，不再交给第二个摘要模型改写。首轮数据不满足问题时，最多追加一次同 Skill 查询；两次取数后仍不满足就明确说明并保留最后实际表格，不把区间数据改称单日数据。

## 最小实现与执行边界

- [查询路由](../ashare_lab/api/routes/strategy_drafts.py) 的 `_review_live_query_result` 接收用户问题及实际返回快照，保留已尝试查询，补查预算从 1 降至 0。普通筛选和推荐前的筛选调用选股 Skill，已知标的查数仍调用查数 Skill，不把补查换成另一条取数链。
- 快照包括实际列名、表格样本、数量、提供方 `provider_metadata` 和抓取时间；查数快照保留提供方字段、单位与日期轴。请求里写了某个周期不等于接口已经返回该周期，抓取时间也不等于行情日期。提供方元数据由 [MX 适配器](../ashare_lab/adapters/market_data/mx_saas.py) 保留，不用请求回显冒充执行证据。
- [核对合同](../ashare_lab/ports/strategy_advice.py) 的 `QueryDataReview` 返回满足与否、实际证据、可选补查语句和完整回复。[模型适配器](../ashare_lab/adapters/language/vibe_strategy_advice.py) 保留证据、数字、名称代码、预算及重复查询等校验。模型只提出自然语言查询，不获得任意工具执行权限。
- 全市场排名不足时继续全市场筛选，不能只补查首表几只股票就声称它们仍是全市场排名前列。最后核对及正文使用补查后的实际结果，不继续引用首表累计金额或旧字段。
- 普通 screen 核对通过直接返回该次模型完整回答；推荐仍走“核对 → 比较推荐 → 正文”，最多展示三只；已知股票 finance 保留既有最终回答代理。本轮没有把所有分支改成同一套摘要器。
- 核对返回 `None` 时明确提示尚未完成核对并保留数据；两次仍不满足时返回核对模型完整说明，不继续推荐或生成成功正文。补查供应商失败时明确对应 Skill 和失败类别，保留上一次实际取得的表格。
- 这条链路只查询当前数据，不修改已有策略、费用或运行意图。没有新增数据源，也没有执行交易或启动回测。
