# B09／B11：补股票与暂停回测分别理解

日期：2026-09-06。环境：正式本地页面 `5184 → 8011`；真实 DeepSeek、东方财富 Skill 历史数据。未提交、推送或公开发布。

## 本轮结果

“股票等我补充，先别跑”现在等待用户给股票，不主动选票；接着说“东方财富，先别跑”直接绑定股票并停在审阅页，不重复问股票，也不误启动回测。之后明确点击“开始回测”，新报告和 AI 分析完整返回。

这只覆盖 B09／B11 的两处明确失败，状态是局部已修待用户验收；不是 20 轮记忆、所有自由输入或所有组合推荐全面通过。B05 按用户已验收结论保持关闭。

## 原因与修复

- 原股票确认分支只直接处理裸股票名称，混合“不跑”指令时进入只回答、不提取股票的分支。现在复用现有模型结构化澄清，一次判断股票选择与执行意图；不靠新增股票名正则拼接答案。
- 模型返回的执行意图必须带本轮原句中的证据。明确不跑覆盖之前的待执行意图；取消修改不应用新股票；没有有效策略不执行。
- 股票名仍经实际名称解析器核实；歧义给真实候选，候选序号只能指向当前已核实的名称。取数连接错误与名称歧义分开处理，不自动绑定第一只。
- 新规则、人设／灵感输入继续交给原有多轮编译，复用本次判断，避免新股票分支吞掉这些输入或重复分类。
- 仅绑定股票时，以既有成交设置为准，保留买卖、日期、本金和费用，不被重新编译的默认值覆盖。
- 初始策略模型及创意模型增加“用户明确要自己补股票”的输出，并传递到现有主动推荐开关。明确等待时不调用主动选股；单纯缺股票或仅说“先别跑”，不自动等同于拒绝推荐。

涉及现有模块：`clarification_dialogue.py`／`vibe_clarification.py`、`dialogue_turn.py`／`compile_strategy.py`，以及 `candidate_generation.py`／`vibe_candidates.py`、`idea_routing.py`／`vibe_ideas.py`。没有新建语言解析器、行情源或执行引擎。
