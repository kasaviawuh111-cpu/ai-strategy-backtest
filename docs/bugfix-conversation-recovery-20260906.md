# 多轮承接、股票简称与取数错误说明

2026-09-06。本轮针对用户提交的公网005新案例；不改已确认的策略编辑布局、计算规则、默认示例或并发调度。最终发布状态以[008发布记录](release-public-008-20260906.md)为准；006的构建遗漏、007人设回复门禁失败单独留存，不冒充通过。

## 体验与处理原则

| 用户输入／场景 | 本次行为 | 不允许的行为 |
| --- | --- | --- |
| 已有策略后输入“股票换成dfcf，其他不变” | 用已缓存的完整A股名录匹配名称、代码、拼音或首字母；唯一完整别名直接使用，保留原买卖及设置 | 将本地可确认的简称当成网络中断；任意猜一只同名股票 |
| “我想吃的”“明天下雨吗” | 模型回应最新意图；没有天气查询结果就说明能力边界，原策略保留，不触发回测 | 重复上轮无效买入条件，或统一回复“本次修改未完成校验” |
| “我是秦始皇” | 先承接表达、给出风格解释，再生成具体可编辑的策略建议；明确这是待验证的风格映射 | 只陪聊而不补条件；未选择就说“你选的第一组策略” |
| “东方财富均线交叉买，反之卖” | 常见缺省参数可补成可编辑建议，不默认追问每个周期；已有同一规则则如实说明沿用 | 将建议参数说成用户明确指定；相同规则误报修改校验失败 |
| “估值过低的股票反转买” | 保留估值偏好，主动给出可验证的日线策略方向；说明不支持的历史估值条件未进入计算 | 用价格下跌冒充低估值，编造历史PE或验证结果 |
| 自伤求助表达（用户提供的测试案例） | 优先支持与安全确认，暂停交易引导；模型不可用时仍有安全兜底 | 当成买入信号、人设风格或立即催促补策略 |

建议不是自动交易或自动回测授权。明确股票歧义、数据不足和不支持的历史条件仍必须守住校验边界。

## 根因与最小修复

1. **编辑入口把后续自然语言都当作槽位替换。** 编辑模型增加独立的conversation结果；自然回复不能携带策略变更、执行设置或重跑指令。人设和投资偏好仍走既有策略建议链路。
2. **失败输入污染后续上下文。** 没有通过校验的修改不覆盖已确认的策略锚点；无策略变更的闲聊不增加修订、不额外请求股票核验。下一条有效策略可以继续。
3. **展示层摘要覆盖模型已经完成的承接。** 策略建议、配对回复的上下文保留原始理解和未覆盖的条件；多方案仍未选时不把首项写成已选。正文由模型完整组织，不拼接一段固定问句。
4. **联想入口和对话换股的识别能力不一致。** 两者复用同一名录匹配，不为dfcf添加孤立特例。当前随包名录5567条；不是新股和改名永远自动同步。
5. **失败卡把不同的数据错误折叠成一个宽泛错误。** 服务端附带安全、固定枚举的失败原因，前端显示对应可理解说明；不向用户泄露供应商原始响应、凭据或异常栈。保留现有有界重试和严格历史校验，不以无限重试掩盖错误。
6. **初始对话表达校验一次失败就直接结束。** 007公网“我是秦始皇”复验暴露此缺口；008复用既有最多两次调用预算，由模型基于原输入修正结构／表达一次，仍失败则拒绝，不削弱事实和执行校验。008已真实显示风格承接与3组具体可编辑候选。

回测计算仍是既有Python引擎；本轮没有更换撮合、收益率或指标算法。

## 验证和证据边界

- 本地真实模型已验证：换股首字母、求助／饮食／天气连续输入、恢复策略、缺省参数和低估值方向。安全与闲聊不改旧策略、不执行回测；真实模型与取数的最终发布包验收见发布记录。
- 定向合同覆盖create／clarification两种入口、失败后续接、未知股票的闲聊不额外取数、模型夹带执行标志不生效；名录匹配覆盖大小写、代码、拼音、首字母及歧义。
- 错误分类通过故障注入验证。真实数据回测成功只能证明该策略和区间，不代表所有历史字段、股票和日期都已可用。
- 用户截图的`run:eb543d47c1e042a492f2b348cb8c9479`现已无法读回，日志未检索到对应记录；不能事后断言是供应商缺字段、实例重启或服务整体宕机。同期005健康／就绪接口正常，旧成功运行仍可读，只能排除检查时的整体不可用。
- 临时存储跨容器重建的数据留存风险未解决，B29仍按用户要求暂缓；未偷偷引入数据库或付费基础设施。

## 用户可复验的最短路径

先建立一条已有策略，然后依次输入“股票换成dfcf，其他条件不变，先不要回测”→“我想吃的”→“明天下雨吗”→“东方财富均线交叉买，反之卖”。应逐轮回应当下意思，最后能回到可编辑规则，不再重复旧错误。新对话输入“我是秦始皇”，应先承接再显示具体方案，而不是要求机械补字。

剩余长对话、长历史和微信真机问题继续见[当前待办](bug-backlog-and-acceptance.md)，不被本轮几个成功案例冲销。
