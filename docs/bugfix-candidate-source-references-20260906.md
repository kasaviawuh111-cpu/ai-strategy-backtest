## 改动边界

只修改 `ashare_lab/adapters/language/vibe_candidates.py` 的模型传输适配：

1. 服务端按原文位置产生 `sourceFragments`，每片含稳定的本轮编号与原始文字。标点和买卖动作仅用于定位，不生成策略条件；不按“且／或／、”拆散复合条件。
2. 模型在原有证据字段中返回 `first_fragment / last_fragment`，不再抄写证据、计算字符偏移。连续范围包括所有中间原文，不能拼接不连续文字。前置动作、无标点句和重复原句均有定向覆盖。
3. 程序将引用还原为现有 `start / end / text`，下游 API、存储、Catalog、参数、方向、AND/OR、漏条件校验保持原样。旧精确 span 仍可读，混合两种格式、未知编号、倒序编号被拒绝。
4. 股票名称只在模型选中的原文范围内唯一精确定位，不猜名称或证券代码。
5. 结构校验失败进入已有修复预算：最多两次候选模型调用，第二次仍失败就停止。修复轮保留同一片段表；日志只记安全字段路径与错误类型，不输出 Pydantic 原始输入或凭证。

没有改前端布局、买卖参数、Python 回测引擎、行情缓存、模型选择、思考开关或公网环境。未引入规则兜底、默认条件替换或无限重试。
