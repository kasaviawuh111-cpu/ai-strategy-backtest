## 本轮修改

1. MX 默认读取预算对齐 Skill 的 120 秒；建连仍有 10 秒上限，保留显式配置覆盖、TLS 校验和现有兼容传输。
2. 移除本地 Skill app 的两次重试覆盖，使用适配器已有的最多三次有界重试；不无限等待，不重复调用模型填补数据。
3. 按固定工具标识、错误类别及 HTTP 状态分类失败。读取超时、连接超时、连接中断、授权失败、服务异常不再全部显示“连接失败”。日志不记录 Key、请求头、供应商正文或异常详情。
4. “重新读取”保留当前策略、日期及费用，创建新回测并强制取数；“修改规则”保留当前策略供编辑，不清空、不选股、不换示例。
5. 未改 RSI、成交额、买卖触发、复权和撮合算法；未接入其他数据源，未缩短六年区间。
