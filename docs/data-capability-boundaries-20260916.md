# 当前本地数据能力边界

核查对象：本地5184/8011；2026-09-16读取实际`/api/v1/capabilities`及私有Parquet元数据。不是公网版本验收，也不是对供应商全量产品能力的承诺。

## 接入与可用性分开

当前接口暴露37种技术/行情指标走`provider_indicator`，另有`provider.numeric`、`provider.series_compare`走按请求发现的历史数值路径。能查询不等于能回测：须核对股票、字段含义、单位、参数、日期完整性及可得时点。

技术指标包括MA、MACD、KDJ、RSI、CCI、BOLL、EMA、ATR/NATR、ADX/DMI、OBV、BIAS/EMA乖离、ROC、动量、BBI、Williams R、随机指标、唐奇安通道、收益波动率等；行情条件包括收盘价、涨跌幅、连续上涨、滚动新高、振幅、成交额/量、换手率、相对成交量、量价确认/背离。具体触发与参数以Catalog及API返回为准。

默认走供应商指标；仅已有确定公式且输入依赖可用的指标可回退到本地计算，实际来源必须记录。`skill_indicator_routes.py`给出回退规则，不能把所有目录指标都宣称为供应商保证提供。

PE/ROE等目录外数值通过历史数值发现通道按请求验证；不得声称`valuation.pe_ttm`已是普通可执行Catalog指标。没有真实、可追溯历史序列时不能用最新财务值填满过去日期。

## 频率与预热

本次核对的KDJ、RSI、MACD、滚动新高、相对成交量、provider.numeric均为1d。分钟价格计划/保护/撮合和分钟技术指标是不同能力，不能因为存在分钟行情就宣称全部指标支持分钟频率。

API默认预热栏：KDJ10根、RSI16根、MACD35根、滚动新高21根、相对成交量23根、provider.numeric1根。参数改变后需按实际依赖计算，不能把默认数量用于所有参数组合。

## 区间建议约束
