# 单股策略组合本地验收

本地入口：http://127.0.0.1:5184/ 。本批为单只沪深A股的规则组合，不是多股票组合；未部署公网。当前本地工作区含其他未提交变更，不冒称clean-SHA发布包。

## 能力和边界

- 指标条件支持且/或；独立买卖计划不因叙述顺序建立成交依赖，明确顺序条件保留上一阶段成交前提。
- 网格、条件、定时三类计划可分属买入与卖出；共享一个账户，不重复本金和持仓。原单计划及计划配指标路线保留。
- 定投附带持有期限等退出规则现在可在高级设置核对、修改；编辑一侧保留另一侧，费用等共享字段同步。
- 不支持的执行方式及缺少数据仍明确拒绝，不改日期、不降频、不造行情。分钟网格成交后移动基准等既有不支持模式，不作为本批新增承诺。实际支持受Catalog、执行路线与数据检查约束。

## 自动回归与证据边界

- 九类买卖计划配对有真实准备/排队/账本/报告接口回归，但行情为合成，不能算九类真实模型稳定率。
- 编译、精确原文来源、语义复核、共享账户及分腿编辑已有针对性回归；本轮新修的定投退出编辑5项及类型检查通过。
- 这些是代表性功能验收，不是全A股、全日期、任意表达的100%通过率，也不是策略收益有效性证明。数据可用性逐次检查。

## 用户验收建议

在本地新建会话，分别试定投配指标、网格配定时卖出、条件且/或；核对审阅卡，再修改一侧参数，确认另一侧未变。可直接使用开发记录中的完整原句复测。

公网发布仍需用户验收后进行，发布前固定版本与本地数据配置并复核同版；本文件不授权发布。历史/观点选股路线沿用已有功能，本批不声称其所有表达都经过重新验收。
