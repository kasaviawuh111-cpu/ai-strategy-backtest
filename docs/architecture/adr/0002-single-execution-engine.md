# ADR-0002：只保留一个权威执行内核

- 状态：Accepted
- 日期：2026-08-28

## 决策

经典策略、指标组合、事件策略和后续模板都只产生统一的 `SignalFact` 与 `OrderIntent`，全部进入同一订单状态机、A 股撮合器和账户账本。

同期买入持有也不能另写价格捷径：它从同一初始资金出发，复用同一费用、滑点、整手、涨跌停、PIT 容量和公司行动账户语义，只改变“首个可成交日买入后不主动卖出”的决策规则。

现有 `backtest_engine.py`、`backtest_custom_engine.py`、`simulator.py`、网格引擎及 Numba 副本只用于迁移对照。新 API 不得直接调用它们。

## 原因

现有入口对 T+1、涨跌停、止盈止损、费用和成交时间的处理不一致，并存在区间外退出价格泄漏。继续复用多套撮合会让同一句策略因入口不同产生不同结果。

## 性能策略

先建立正确的事件驱动权威实现。NumPy/Numba 只能替换已通过同一黄金测试的纯计算内核，不能复制业务状态机。
