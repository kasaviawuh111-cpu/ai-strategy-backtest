实施更新：第二版已接入正式本地页面，并完成原位换股→真实新回测→查看新旧报告的链路；已增加证券身份持久缓存。具体来源、速度、运行编号和未覆盖边界见 [B28 实施记录](../../docs/bugfix-inline-stock-search-20260906.md)。下方“已核实的数据及接线”和“第二版验证边界”保留的是设计阶段的 as-is 与 file 预览记录，不再表示正式页面尚未实施。B28 仍等待用户体验验收，不代表公开发布。

实施补充：正式输入框查询东方财富实际证券搜索结果，覆盖沪、深、北交易所 A 股名称片段、代码及提供方支持的简拼；仅返回身份，不在这里推荐策略或查询历史行情。选择实际候选后复用结构化草稿修改接口，只更换股票，不再把明确选择送模型猜一次。预览 v2 保留为静态设计历史，验收以正式 localhost 页面及真实请求为准。空结果、连接失败分开显示；输入防抖和取消过时请求，不能让迟到结果覆盖新输入或新会话。

沿用当前卡片，点击股票名称后，名称就在原位置变成输入框并自动全选。匹配结果出现在同处下方，点击一项或按 Enter 确认后，立即替换股票名称／代码并收起；不跳转对话、不显示下方完整槽位、不再加“确认修改”步骤。Esc 或取消恢复当前已保存的股票，清空时保留编辑框让用户重填，不能提交空值。中文输入法选词时不将 Enter 当作提交。

只换股票时，保留当前完整草稿的规则、日期、本金、滑点与费用；不从旧报告拿参数覆盖当前未保存的编辑。历史报告只读，修改生成新草稿。正式实现必须先完成身份核实及草稿保存，才能更新为新股票；核实中显示就地状态并禁止对尚未确认的股票开始回测，不能乐观地用输入字符串冒充已确认身份。仅换股票停在审阅页，用户仍点“开始回测”才执行。

本版只评审入口及槽位衔接，不实施 B19 的条件分组或 B20 的状态文案。左侧其他规则沿用现有未分组外观；v4 分组和无框区间设计继续单独待确认。
