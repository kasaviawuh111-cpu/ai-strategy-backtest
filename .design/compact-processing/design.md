# 单一处理过程入口

用户已确认 v2：处理中默认展开；手动收起后不因推流重新展开；完成后自动收起，可重新展开回看。正文内模型公开说明保持正常展示。

## 实现范围

复用 `ModelReasoning` 与原有进度事件，合并 `ThinkingStream` 的重复标题、状态段落和单独日志入口。不增加模型调用，不编造阶段或补齐未返回的内容。

折叠头只显示“处理过程”和当前状态。内容最高 160 CSS px，可滚动；往上阅读时停止自动跟随。实际服务消息最多展示最近四条。失败说明留在正文，不隐藏失败。

入口：`web/src/components/ModelReasoning.tsx`、`primitives.tsx`、`BacktestReview.tsx`、`SummaryCards.tsx`、`App.tsx`。样式沿用 `app.css` 的颜色和字体。
