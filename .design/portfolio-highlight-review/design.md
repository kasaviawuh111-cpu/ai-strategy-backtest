# 持仓高光复盘 H5 设计契约

## AS-IS 基线

- `v1.html` 是从 Claude 临时工作区恢复的逐字节副本，作为已确认的黑色动效视觉基线。
- 基线已有账户曲线、高光卡、故事播放器、归因、持仓矩形树图、每日节奏和导入底部面板。
- 基线中的账户曲线、收益、事件和高光由浏览器随机数生成，不能作为真实客户复盘结果。
- 基线引用 Google Fonts 和 CDN 版 SheetJS，不是完整的本地离线产品。

## TO-BE 产品契约

### 首屏与导入门槛

- 客户未导入数据时，不展示任何伪造的账户数字或高光。
- 第一步至少导入期末持仓；导入后先预览、校验并由客户确认。
- 界面以“可用能力”区分快照、交易复盘、账户收益、持仓归因和逐 tick 回放，数据不足时明确降级。

### 市场与账户边界

- 首版 profile 为 `CN_A_HK_CASH_V1`：现金账户、多币种估值，支持 A 股和港股。
- 首版不宣称支持融资融券、卖空、期权、期货或场外衍生品。
- 以用户选定的基准币种展示账户值；非基准币种记录必须提供可审计的汇率或已折算金额。

### 复盘证据分级

- 仅期末持仓：支持仓位快照、权重和有成本时的浮动盈亏；不生成区间收益、归因或历史高光。
- 增加成交流水：支持按真实成交时间回放客户操作；未提供行情 tick 时，不伪造盘中价格路径。
- 增加每日账户净值和外部资金流：才计算 TWR 区间收益、回撤和日级高光。
- 增加分证券估值/盈亏或行情 tick：才开放对应粒度的持仓归因和真实 tick 回放。

### 高光战报

- 点击高光后进入沉浸式全屏播放器，时间线按导入记录的真实顺序推进。
- 关键操作可触发聚光、粒子、连击标识、收益计数和归因卡，但动效不改写证据。
- 播放器显式显示粒度：“真实行情 tick”、“成交级操作 + 日级净值”或“日级回放”。
- 高光数量为 0–5，只在规则有足够证据时生成，不为凑数量填充。

### 响应式与动效

- 同一个 H5 在桌面端与手机端自适应，无水平滚动。
- 桌面端优先展示账户曲线与归因并排；手机端改为单列、底部导入和全屏播放。
- 支持 `prefers-reduced-motion`；在减少动效模式下保留状态与结果，去掉粒子和剧烈过渡。
